# CLAUDE.md — Архитектурная конституция проекта myBTDBs

## 1. Стек и целевая платформа
- **Язык:** Rust (Edition 2021).
- **Движок:** Bevy 0.15 (2D-режим, рендер через `bevy_sprite` / `bevy_ui`, математические коллизии без тяжелой физики).
- **Платформы:** Android (`aarch64-linux-android` через `cargo-apk`, цель — Honor 10X Lite, 2400×1080, Landscape) и Desktop (Windows/Linux).
- **Точки входа:** `src/lib.rs` содержит `#[bevy_main] pub fn main()`, `src/main.rs` вызывает `btd_clone::main()`.

## 2. Жёсткая архитектура слоёв
- `src/core/` — общие состояния игры (`GameState`), маркеры сторон (`Side`), события (`Events`), ресурсы игрока/бота и унифицированный ввод (`PointerInput` для мыши и тачскрина).
- `src/data/` — статические конфиги и балансы (параметры шаров, башен, апгрейдов, волн, координат карт). Никаких магических чисел в системах!
- `src/plugins/` — изолированные Bevy-плагины по игровым доменам (`map`, `bloons`, `towers`, `economy`, `ai`). Плагины общаются через `Events` и общие `Resources`, не залезая во внутренности друг друга.
- `src/ui/` — экраны и HUD на базе `bevy_ui`. UI только читает ресурсы/события и отправляет команды (`EventWriter`), никаких расчётов баланса внутри UI.
- `src/utils/` — чистые математические функции без состояния (дистанции, проверка попадания в круг, расчёт пути).

## 3. Запреты и лимиты
- **Тонкая точка входа:** `src/lib.rs` только настраивает окно и регистрирует плагины.
- **Лимит файла:** максимум 350 строк на один `.rs` файл.
- **Мобильный UX:** все кнопки UI не меньше 48×48 логических пикселей, управление работает без правой кнопки мыши и клавиатуры.
- **Проверка сборки:** перед выдачей ответа проверять все импорты, типы и совместимость с API Bevy 0.15.
